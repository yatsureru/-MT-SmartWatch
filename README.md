# [MT] SmartWatch
Project Zomboid Build 42.21

## Возможности
- функциональные чипы всегда активны, пока установлены — тумблера нет, цена функции = цена чипа;
- app-чипы тратят заряд, только пока приложение открыто;
- снятие ядра с чипами заблокировано — это неявно защищает от сиротских чипов;
- двигатель авто не перезапускается после EMP, сиротские локи гасят свет, кулдаун wall-clock.
